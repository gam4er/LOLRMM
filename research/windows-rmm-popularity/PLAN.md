# План исследования (по шагам, с промежуточными артефактами)

## Шаг 1. Инвентаризация репозитория
- Просмотреть `yaml/` и выделить легитимные утилиты удалённого доступа, релевантные Windows.
- Просмотреть `detections/sigma/` для проверки наличия IoC/детектов (как вспомогательный контекст, не основной критерий популярности).
- Артефакт: `01_candidates_from_repo.csv`.

## Шаг 2. Внешняя оценка популярности (2020–2025)
- Для каждой утилиты собрать внешние признаки:
  1) упоминания в публичных IR/Threat Intel отчётах,
  2) применимость к ATT&CK T1219 (Remote Access Software),
  3) частота в кейсах red team/pentest.
- Построить агрегированный балл и ранжирование Top-20.
- Артефакт: `02_external_scoring_top20.csv`.

## Шаг 3. Классификация по типу доступа
- Для каждой утилиты определить модель:
  - `bind` (слушает входящие подключения),
  - `proxy/broker` (через промежуточный сервер).
- При гибридной модели указать «гибрид» с пояснением.
- Артефакт: включено в `02_external_scoring_top20.csv`.

## Шаг 4. Хранение настроек в Windows
- Для каждой из Top-20 собрать:
  - ключи реестра,
  - пути к конфигурационным файлам,
  - примечание по вариативности (portable/service/unattended).
- Если достоверность недостаточна — явно отметить.
- Артефакт: `03_windows_config_locations.csv`.

## Шаг 5. Итоговый отчёт
- Подготовить подробную русскоязычную сводку + Markdown-таблицу Top-20.
- Включить ссылки на проект (GitHub или вендор), ссылку на карточку в `yaml/`, классификацию и хранилище настроек.
- Артефакт: `README.md` в этой папке.
